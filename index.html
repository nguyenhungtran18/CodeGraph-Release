💻 Installation & Setup

CodeGraph is packaged as a standalone executable (`.exe`). No complex installation, no Python configuration required.

Cursor / Windsurf Integration

Go to Settings > MCP Servers > Add New:

  • Name: CodeGraph
  • Type: command
  • Command: "C:\Path\To\CodeGraph-MCP.exe"

Claude Desktop Integration

Add the following snippet to your %APPDATA%\Claude\claude_desktop_config.json:

{
  "mcpServers": {
    "CodeGraph": {
      "command": "C:\\Path\\To\\CodeGraph-MCP.exe"
    }
  }
}
