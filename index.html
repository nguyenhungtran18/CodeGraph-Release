CodeGraph

C/C++ TokenVector Core 100% Local-First MCP Native for Cursor Zero-Token Indexing

"Đôi mắt" phân tích kiến trúc mã nguồn đỉnh cao dành cho AI Coding Assistant (Cursor, Claude, Windsurf). Tốc độ ánh sáng, bảo mật tuyệt đối.

CodeGraph giải quyết triệt để rào cản lớn nhất của AI hiện nay: "Mù cấu trúc dự án". Thay vì đốt tiền vào Vector Embeddings hay gửi code lên Cloud, CodeGraph sử dụng lõi nhị phân siêu tốc C/C++ (TokenVector) để mổ xẻ mã nguồn ngay trên máy bạn. Chỉ trong vài giây, nó dựng lên một bản đồ tư duy chính xác 100% để bơm thẳng vào não AI thông qua giao thức MCP.

⚡ Hiệu năng Đột phá (Bản quyền v1.0.0)

Kiến trúc mới thay thế hoàn toàn Python AST cũ bằng 18 lõi nhị phân C++ (Binaries), mang lại sức mạnh vượt giới hạn:

Chỉ số kiểm thử Kết quả thực tế Sự khác biệt
Tốc độ quét (760+ files) < 1.2 giây Nhanh gấp 10 lần so với trình AST cũ. Cảm nhận độ trễ gần như bằng 0.
Độ chính xác truy vết 100% Deterministic Không đoán mò bằng xác suất (Vector). Truy vết Call & Inherit chính xác tuyệt đối.
Tiêu thụ RAM ~12 MB RAM Siêu nhẹ. Không cần chạy nền Database hay Vector Store.
Bảo mật mã nguồn Offline 100% Code không bao giờ rời khỏi máy. Được bảo vệ bởi lớp mã hóa PyArmor chống dịch ngược.

Tự động tính toán các file phụ thuộc xung quanh điểm bạn đang code, gom vừa vặn giới hạn Token. Ngừng việc ném rác vào Prompt.

🕸️ Giao diện Đồ thị Obsidian

Kết xuất kiến trúc thành file HTML5 trực quan, tích hợp vật lý động. Quan sát mối liên kết hàng nghìn file chỉ với cái cuộn chuột.

🔌 Cắm là chạy (MCP)

Được đóng gói chuẩn hóa dưới dạng MCP Server. Tương thích ngay lập tức với Cursor, Windsurf, hoặc Claude Desktop.

💻 Hướng dẫn Cài đặt & Cấu hình

CodeGraph được đóng gói thành file thực thi độc lập (Standalone `.exe`). Không cần cài đặt rườm rà, không cần cấu hình Python.

Tích hợp vào Cursor / Windsurf

Mở Settings > MCP Servers > Add New:

  • Name: CodeGraph
  • Type: command
  • Command: "C:\Đường\Dẫn\Tới\CodeGraph-MCP.exe"

Tích hợp vào Claude Desktop

Thêm đoạn sau vào %APPDATA%\Claude\claude_desktop_config.json:

{
  "mcpServers": {
    "CodeGraph": {
      "command": "C:\\Đường\\Dẫn\\Tới\\CodeGraph-MCP.exe"
    }
  }
}
